📚 Knowledge Vault

Knowledge Vault is an interactive, content-rich web platform designed to serve as a centralized repository for educational resources. It features a clean, organized UI that allows users to browse and discover curated technical knowledge across various categories.

📸 Screenshot

![Knowledge Vault Screenshot](./assets/Knowledge%20Vault.png)


⚙️ Tech Stack

HTML5, CSS3, Google Fonts, and FontAwesome.

✨ Main Features
📂 Display knowledge/resources in a structured way
🔍 Search and filter functionality
📱 Fully responsive design
⚡ Fast and interactive UI
🎨 Clean and modern design


📦 Dependencies
react
react-dom
tailwindcss
daisyui
vite

🚀 Run Locally

Follow these steps to run the project on your local machine:

1️⃣ Clone the repository
git clone https://github.com/kazij317-code/B13-A01-Knowledge-Vault.git
2️⃣ Go to project folder
cd B13-A01-Knowledge-Vault
3️⃣ Install dependencies
npm install
4️⃣ Run the project
npm run dev
5️⃣ Open in browser
http://localhost:5173
